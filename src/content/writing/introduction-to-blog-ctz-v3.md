就在刚才，我命运多舛的博客迎来了第三个版本。

![图1 Blog CTZ V3 首页](./images/introduction-to-blog-ctz-v3/图1%20Blog%20CTZ%20V3%20首页.png)
图1 Blog CTZ V3 首页

原本是又一次被粉色软件所裹挟，把某个博客框架加入了稍后再看——或者更早些，从我想要大改 V2 版本的博客框架却又无从下手开始。

![图2 ZCode 对 Blog CTZ V2 的评价](./images/introduction-to-blog-ctz-v3/图2%20ZCode%20对%20Blog%20CTZ%20V2%20的评价.png)
图2 ZCode 对 Blog CTZ V2 的评价

……或者从 ZCode给我列了数十条修改建议开始。

总之，在一个灰蒙蒙的上午，当我因为种种原因而无故内耗时，偶然瞥见待办里停留着一项任务——“Blog CTZ V3 初始化”。我没有像往常一样读一本心理学科普书来做心理按摩，而是选择部署博客来转移注意力。

有趣的是，这是一个让我逃离 AI 的博客，仅仅因为这一个原因，就让我对它充满了期许。

在前两个博客中，由于正在对 vibe coding 上头，我选择直接把模板库和文章发给 AI，让它们直接帮我搭建和部署。有什么不称心的，我选择直接和它们聊，让它们按照我的想法把博客改成我想要的样子。

![图3 Blog CTZ V1 和 V2 的模板大致长这样](./images/introduction-to-blog-ctz-v3/图3%20Blog%20CTZ%20V1%20和%20V2%20的模板大致长这样.png)
图3 Blog CTZ V1 和 V2 的模板大致长这样

![图4 被我魔改后的首页（Blog CTZ V1）](./images/introduction-to-blog-ctz-v3/图4%20被我魔改后的首页（Blog%20CTZ%20V1）.png)

图5 在我魔改下增加的属性筛选（Blog CTZ V1）

为了让内容能更符合我的需求，我大刀阔斧地增加了更新量统计、头像、文章类型、属性筛选等。但最终改出了一个大屎山。

每一个新功能都伴随着更多的“屎债”，最终导致我什么功能都不敢加了。

![图6 文章列表页（Blog CTZ V2）](./images/introduction-to-blog-ctz-v3/图6%20文章列表页（Blog%20CTZ%20V2）.png)
图6 文章列表页（Blog CTZ V2）

比如在 Blog CTZ V2 里，尽管我已经很保守地决定少改模板内容，但这个文章的信息密度我是真受不了，就光是想把两个文章的间距调小都一直没 vibe 成功。

最终，我越来越意识到模板的重要性。一个符合我使用习惯的模板，可以事半功倍——vibe coding 让我误认为可以抛弃的模板，反而让我拾起了写作的兴趣。

![图7 Blog CTZ V3 关于页](./images/introduction-to-blog-ctz-v3/图7%20Blog%20CTZ%20V3%20关于页.png)
图7 Blog CTZ V3 关于页

诚然，Blog CTZ V3 的模板不是完美的，比如它这个巨大的标题我就觉得有点儿太浮夸。但我必须承认，我真的很认可作者“Fourfold”的理念——以写作、项目、研究和设计四个板块为核心，分别对应费曼学习法的结果、项目记录、闪念和视觉内容。这非常符合我在卡片笔记写作法中学到的东西。

![图8 Blog CTZ V3 开始页](./images/introduction-to-blog-ctz-v3/图8%20Blog%20CTZ%20V3%20开始页.png)
图8 Blog CTZ V3 开始页

还有一个很有趣的点，是开始页给了三个连接，分别是通向文章系列、标签和搜索的。因为文章系列太有 J 人的感觉了，我不禁给它魔改了一番。

总而言之，言而总之。我写作没有什么别的目的，主要是为了表达——有时候即使没有反馈，光是表达本身便让我对知识产生了新的理解，而我很享受这个过程。

——谨以此文庆祝这个表达的机会，也欢迎你来 [我的站点](https://chartreuse310.github.io/blog-ctz-v3/) 看一看。
